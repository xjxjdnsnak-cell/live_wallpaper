# LUMINA Wallpaper

## v0.6.0 新增

- 从编辑器生成视频壁纸副本：编辑页新增“生成壁纸副本”，会按当前配置输出新的本地 MP4。
- 起止时间裁剪：使用 `startMs` / `endMs`，结束时间小于或等于起始时间时会阻止生成并提示错误。
- 输出位置：生成文件写入 App 私有目录 `generated_wallpapers`。
- 自动入库：生成成功后自动创建新的 `WallpaperItem`，名称为原名称加 `_已适配`，可预览、收藏、分类、搜索、删除、设为当前动态壁纸。
- 默认静音：当前实现只复制视频轨，不写入音轨；生成壁纸配置也会保存为静音。
- 生成壁纸详情：详情页会显示“已适配”、来源、生成时间和生成方式。
- 删除清理：删除生成壁纸时，会清理 App 私有 `generated_wallpapers` 目录中的对应文件，不会删除用户原始视频。

## v0.6.0 效果说明

- 已真实烘焙进 MP4：起止时间裁剪、视频轨复制、音轨移除。
- 保留为配置：播放速度、填充模式、亮度、对比度、饱和度、色温、曝光、缩放、偏移、旋转、镜像、暗角、渐变、文字层。
- 真实桌面动态壁纸端继续读取配置并应用：静音、播放速度、填充模式、起止时间片段循环。
- 第一版不烘焙滤镜、文字、构图变换和速度变更；这些效果仍依赖预览页近似展示或运行时配置。
- 裁剪使用 Android 平台 `MediaExtractor` / `MediaMuxer`，起点可能贴近关键帧，不支持复杂剪辑、导出到系统相册或批量生成。

## v0.5.1 新增

- 高级编辑面板：编辑页按“播放 / 构图 / 调色 / 氛围 / 文字 / 预设”分组。
- 调色参数：亮度、对比度、饱和度、色温、曝光。
- 构图参数：填充模式、缩放、水平偏移、垂直偏移、旋转、镜像。
- 遮罩参数：暗角、顶部渐变、底部渐变，并保留预览模糊。
- 文字层：支持开关、文字内容、顶部/居中/底部位置和透明度。
- 预设滤镜：原图、清冷、暖阳、电影、暗夜、柔和、赛博。
- 配置保存和重置：支持分组重置、重置全部、应用预设，配置继续保存在本地壁纸库 JSON 中。
- 详情页编辑摘要：显示当前预设、速度、填充模式、静音状态、裁剪片段、调色/遮罩/文字状态。

## v0.5.1 效果说明

- 真实桌面动态壁纸端已生效：静音、播放速度、填充模式、起止时间片段循环。
- 编辑器/预览页已生效：缩放、偏移、旋转、镜像、亮度、曝光、色温近似、暗角、顶部/底部渐变、文字层、Android 12+ 预览模糊。
- 预览近似效果：对比度、饱和度、色温目前使用轻量遮罩近似，不做视频像素级处理。
- 仅保存配置、等待后续渲染方案：真实壁纸端的调色、模糊、渐变、文字、复杂构图变换。当前仍以稳定播放 ExoPlayer Surface 为优先，不在真实壁纸 Surface 上强行叠 Canvas 滤镜。
- 不支持复杂视频剪辑、转码、FFmpegKit 或 OpenGL 渲染。

## v0.5.0 新增

- 壁纸编辑页：详情页可进入“编辑壁纸”，支持视频预览、保存和重置。
- 每个壁纸独立配置：`WallpaperItem.config` 保存填充模式、播放速度、静音、起止时间、亮度、模糊和暗角。
- 当前壁纸配置同步：设为当前壁纸时会同步 `video_uri`、当前壁纸 id 和当前配置，`WallpaperService` 会实时应用速度、静音、填充模式和片段循环。
- 片段循环：支持 `startMs` / `endMs`，真实壁纸端和预览端都会在结束点回到起始点。
- 预览效果：预览页和编辑页支持亮度遮罩、暗角遮罩；模糊保留为实验设置。
- 详情页配置摘要：显示当前填充模式、速度、静音状态、片段范围和视觉效果状态。

## v0.5.0 已知限制

- 真实壁纸端暂不实现亮度、模糊、暗角滤镜；这些效果目前主要在 App 预览/编辑页展示。
- 模糊是实验设置，第一版不做真实视频模糊处理。
- 不支持复杂时间轴、视频剪辑、转码或导出。
- `STRETCH` 在真实 `WallpaperService` Surface 上仍依赖 Media3 scaling mode，可能不是严格像素级拉伸。

LUMINA 是一个 Kotlin Android 动态壁纸 App。核心能力已通过真机测试：选择本地视频、持久化 URI、设置为系统动态壁纸并在桌面循环播放。v0.4.0 在 LUMINA 风格 UI 基础上加入真实本地壁纸库、收藏、分类、浏览历史和搜索。

## v0.4.0 新增

- 本地壁纸库：导入的本地视频会保存为 `WallpaperItem`，包含 URI、文件名、时长、大小、缩略图路径、分类、收藏状态、创建时间、最近浏览时间和使用次数。
- 多视频导入：底部中间加号和“添加视频”支持选择多个 `video/*`。
- 持久化：使用 DataStore 保存本地壁纸库 JSON、当前壁纸 id、收藏状态、浏览历史和使用次数。
- 首页真实数据：Banner 优先展示当前壁纸，每日推荐展示本地导入视频；无数据时显示空状态。
- 分类页真实数据：显示每个分类下的本地视频数量，并按分类筛选。
- 详情页真实操作：设为当前壁纸、预览、设置为系统动态壁纸、收藏/取消收藏、删除、修改分类。
- 收藏页：显示真实收藏列表，支持取消收藏。
- 我的页：显示导入数量、收藏数量、浏览历史数量、当前壁纸、最近浏览和最常使用。
- 搜索：首页按本地视频文件名搜索。

## 页面

- 启动/品牌页：展示 `LUMINA / WALLPAPER`。
- 推荐首页：搜索、精选 Banner、快捷入口、当前视频、每日推荐、热门标签。
- 分类页：风景、动漫、游戏、插画、科幻、视觉、艺术、建筑、动物、其他。
- 详情页：视频信息、分类、收藏、删除、设为当前、预览、设置动态壁纸。
- 收藏页：真实收藏列表和空状态。
- 我的页：个人信息、本地统计、当前壁纸、最近浏览、常用壁纸。
- 底部导航：首页、发现、中间加号、收藏、我的。

## 已实现核心能力

- 本地视频 URI 持久化读取权限。
- DataStore 保存设置和本地壁纸库。
- Media3 ExoPlayer 在 `WallpaperService` Surface 上循环播放当前 `video_uri`。
- 清除或删除当前壁纸后，真实壁纸端显示占位提示。
- 播放错误写入 Logcat，普通 UI 只显示用户可读摘要。
- 无视频、无缩略图、元数据读取失败时不崩溃。

## 已知限制

- 无联网壁纸库。
- 无账号系统、广告、云同步。
- 分类需要用户在详情页手动设置；默认分类为“其他”。
- 缩略图生成失败时使用渐变占位图。
- 热门标签和“我的合集”仍是 UI 占位/mock，不接入真实远程内容。
- 不实现真实下载功能。
- 不实现 iOS Nugget / PosterBoard / MobileGestalt / SpringBoard / sparserestore / BookRestore。
- 不实现 `.tendies` 完整兼容。
- 不实现 root / Shizuku / ADB / 无障碍 / 悬浮窗权限能力。

## 手动测试

1. 启动 App，确认进入 LUMINA 首页。
2. 点击底部中间加号，选择多个本地视频。
3. 重启 App，确认本地壁纸库仍存在。
4. 首页确认 Banner 和每日推荐显示真实导入视频。
5. 搜索框输入视频文件名片段，确认能筛选本地视频。
6. 进入分类页，确认每个分类显示真实数量。
7. 进入详情页，修改分类、收藏/取消收藏。
8. 在详情页点击“设为当前壁纸”，再点击“设置为动态壁纸”，确认桌面播放该视频。
9. 收藏页确认显示真实收藏。
10. 我的页确认导入数量、收藏数量、最近浏览和常用列表。
11. 删除非当前壁纸，确认只从库中移除。
12. 删除当前壁纸，确认 `video_uri` 被清空，壁纸端显示占位页。
13. 进入某个壁纸详情页，点击“编辑壁纸”，设置起止时间后点击“生成壁纸副本”。
14. 生成成功后点击“查看详情”，确认新壁纸显示“已适配”并出现在本地壁纸库。
15. 将生成壁纸设为当前，再进入系统动态壁纸设置，确认桌面可播放生成后的 MP4。
16. 删除生成壁纸，确认原始视频仍保留，生成文件从 App 私有目录清理。
